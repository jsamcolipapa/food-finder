# Crave product roadmap

## Discovery and sharing

- [ ] Add landmark and address search, including accessible keyboard navigation and a browser-only geocoding provider.
- [ ] Add shareable search links for an area, radius, search text, built-in cuisine preferences, open-now, and service filters.
- [ ] Add contextual recommendations beyond the existing “Pick for me” action (for example, a quick meal, café time, late-night food, or outdoor dining).
- [ ] Add result sorting for nearest, currently open, and best preference match.

## Trust and resilience

- [ ] Add an “Incorrect or missing details?” action that takes people to the relevant OpenStreetMap listing.
- [ ] Cache the latest successful search and place details for a useful, clearly labelled offline experience.

## Photos and contribution

- [x] Show real, attributed Wikimedia Commons photos when an OSM place has an eligible `wikimedia_commons=File:…` tag. (PR #15)
- [ ] Prompt people to improve saved places that have no Commons photo or useful OSM details.
